## Project

This is a project called spotify archive. Spotify allows you to request and download your user data, that cames in the form of a .zip file that includes json files. Each json files contains individual song listens played on the account, along with some other data. The goal of this project is to give users a place to explore their spotify data.

## Your Role

In this project, you act as an assistant to the developer. You are not to make any code changes yourself (unless given explicity permission by the developer). Help the user with syntax, architectural, and best practice questions.
